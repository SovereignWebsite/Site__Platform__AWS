# 15: R-026, the CloudFront flood cost (for cloudformation.aws.a and security.aws.a)

About vault-edge.yaml 0.4.0 and vault.yaml 0.5.0 (work/cloudformation.aws.a c30353d). AWS's public pages only, read 23 Nov 2026; anything not stated is "to confirm".

| # | Question | Verdict | Source and note |
|---|---|---|---|
| 1 | WAFv2 web ACL with Scope CLOUDFRONT in us-east-1; ARN form | Confirmed | AWS::WAFv2::WebACL: "For CLOUDFRONT, you must create your WAFv2 resources in the US East (N. Virginia) Region, us-east-1". ARN `arn:aws:wafv2:us-east-1:<acct>:global/webacl/<name>/<id>`: the SAR's resource form is `arn:${Partition}:wafv2:${Region}:${Account}:${Scope}/webacl/${Name}/${Id}`, and the distribution's `WebACLId` example is `arn:aws:wafv2:us-east-1:123456789012:global/webacl/ExampleWebACL/...` ("use the ACL ARN" for WAFv2). So it is a cross-region reference from a stack in another region: the edge stack (us-east-1) is the natural home for the web ACL. |
| 2 | Rate-based rule: minimum Limit, window | Partly: the window is not fixed at 5 minutes | `Limit` Minimum 10, Maximum 2000000000; "The lowest limit setting allowed is 10" (WAF guide). `EvaluationWindowSec`: "Valid settings are 60, 120, 300, and 600" seconds. The window is chosen, and "doesn't determine how often AWS WAF checks the rate". The limit counts per aggregation instance (per IP by default). |
| 3 | Do requests WAF blocks still carry CloudFront's per-request charge? | To confirm for pay-as-you-go | The CloudFront pricing page says of the flat-rate plans that "requests blocked by AWS WAF never count against your usage allowance". For pay-as-you-go pricing, no page read says whether a blocked request is billed as a CloudFront request; do not assume it is free. WAF itself bills per request it inspects (WAF pricing, not re-read here). |
| 4a | Budgets action types | Confirmed | "Your available actions include applying an IAM policy or a service control policy (SCP). They also include targeting specific Amazon EC2 or Amazon RDS instances in your account" (Budgets, configuring actions). |
| 4b | Can any disable a CloudFront distribution? | No, by that list | An IAM or SCP Deny stops new calls; it does not turn a distribution off, and the instance actions cover only EC2 and RDS. Disabling a distribution needs something else (an alarm-driven function calling UpdateDistribution with Enabled false), which is a real change and a plan for Dinis. |
| 4c | How delayed is the cost data? | Confirmed | "AWS Budgets information is updated up to three times a day. Updates typically occur 8-12 hours after the previous update" (Budgets, managing costs). A flood can run for hours before a budget sees it; CloudWatch's CloudFront `Requests` metric (note 04) is the faster signal. |
