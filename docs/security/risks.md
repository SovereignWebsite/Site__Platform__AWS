## Verified, no finding

- Trust: both roles require `accounts.google.com:aud` = the site's client ID and `accounts.google.com:sub` = the owner's subject, with StringEquals (bootstrap.yaml:31-34, :73-76). A Google token for another app or another person cannot assume them. Session length 1 h.
- Stack update flow: the template diff, the change set and the executed change set are built from the same fetched text, the stack name is fixed by the plan, parameters keep their previous values, and two separate clicks are needed (app.js:414-445).
- CSP: `script-src 'self' https://accounts.google.com/gsi/client`, no `unsafe-inline` for scripts, `base-uri 'none'`, `form-action 'none'` (index.html:6). `style-src` allows `unsafe-inline` (low risk, noted only).
- plan.js: IAM trust edits refuse anything but exactly one matching condition, refuse to remove the last subject and change nothing else.
