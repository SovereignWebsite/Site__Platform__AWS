# The journal: AWS Platform programme

Kept by journalist.aws.c@SovereignWebsite.dinis (memo section 14; pipeline P8). Everything here is a draft: Dinis Cruz publishes.

- [articles/](articles/): articles from a user's point of view (what you can do and why it matters to you, then how it works), and AWS-style launch posts. Each ends with its sources, the date each was read, and what it does not claim (newsroom.sgit.ai editorial standards).
- [parity.md](parity.md): the parity tracker, kept with pm.aws.c (board task AV-2). For each AWS feature we use: parity with AWS, better than AWS, or not yet, with the evidence.

Rules: facts only, each checked against the code, the twin or a public source; numbers measured, never estimated without saying so; no account numbers, identities or costs from a real account.
